## 1 定义（`definition`）

肢端肥大症（acromegaly）是一种罕见的内分泌疾病：垂体分泌生长激素（GH）的腺瘤长期过量分泌 GH，
使胰岛素样生长因子-1（IGF-1）升高，进而累及多个器官与代谢系统。起病隐匿、病程迁延。

- 病因口径：本项目文档记录为「垂体生长激素（GH）腺瘤」；诊断与随访以 GH / IGF-1 两组生化指标为主要记录对象。
- 检查项（项目术语表）：GH、IGF-1、口服葡萄糖生长激素抑制试验（OGTT-GH）、垂体 MRI（增强）、视野检查；阈值与判读不抄录。
- 临床按系统分行：面容与肢端改变、糖代谢、心血管、睡眠呼吸暂停、骨关节，拆成四个合并症分节，不合成总分。
- 治疗后可能出现垂体功能减退，需要按轴激素替代；「激素替代档案」为一级页面，按医嘱原文记录。

## 3 目前治疗全景概要（`landscape`）

按治疗方式类别分组，只列指南与共识列举过的手段，不排序、不比优劣、不含剂量与疗程。

### 3.1 手术治疗
- 经鼻蝶窦入路垂体腺瘤切除术：项目术语表另记神经内镜下垂体腺瘤切除术、显微手术等写法；术式与切除范围由神经外科按影像与病理决定。

### 3.2 药物治疗（三类）
- 生长抑素类似物 / 受体配体（SSA / SRL）：以长效注射剂形式出现，本台按注射周期记录计划与实际。
- 多巴胺激动剂；GH 受体拮抗剂（生长激素受体拮抗剂）：共识列举的药物类别。

### 3.3 放射治疗
- 立体定向放射外科（患者俗称「伽马刀」类）与常规分次放疗：项目文档记录为手术、药物之外的补充手段。

### 3.4 治疗后长期管理
- 激素替代：垂体功能减退时按轴替代（糖皮质激素、甲状腺激素、去氨加压素等），按医嘱原文记录，提示不可自行停药。
- 合并症四轨：糖代谢、心血管、睡眠呼吸暂停、骨关节分别记录。
- 随访：GH / IGF-1、垂体 MRI、视野复查，间隔按主诊医嘱。

**固定出口（原话照抄）**：

> 以上是文献与指南里列出的手段，按病期与线序排列，不代表任何一项适合你。选哪一个，这一句需要问你的医生。

## 7 本项目教训

- **「首选」这个词在本病种特别容易滑进来**：项目调研原文写着共识「明确手术为首选治疗方式」。这句话是共识的判断，
  不是本台的表述；写进治疗全景段就等于替医生排了先后。最终改成「手术是治疗方式之一，术式与范围由神经外科决定」。
- **版本号必须从项目文档里取**：2021 版共识的卷期页（中华医学杂志 2021;101(27):2115-2126）来自
  `research-notes/medical-constraints.md`；同一份文件里还记录了「2022 / 2024 版不存在」，所以趋势段只写 2013 → 2021，
  没有编一个不存在的版本更替。
- **国家卫健委指南只核到印发信息**：SPEC 写「2025-07-10 印发，已核实」，核实的是印发这件事，不是拿到原件。
  来源栏因此仍写「未取得原件，据二次来源」，页码待核。
