## 一、总原则

- AI 协助默认：说 / 拍化验单 / 交 PDF → 结构化候选 → 逐项核对 → 确认才入事实层；拒收零副作用。
- 手工永远可及但收敛：「⋯ 更多」收口；每页显式编辑 ≤1；表单 ≤6 字段；数字用键盘组件。
- 删除 = 更正：只新增版本；界面语言"改这一条"。
- 回首页一步：二级页返回 / 顶栏「小肢宝」/ 完成 Toast 内嵌「回到看板」。
- **红线**：不 AI 生成"生化控制/未控制"判定；不 AI 估算任何判定；激素剂量零"建议调整"文案。

## 三、CRUD 双通道矩阵

| 实体 | AI 协助（默认） | 手工（收敛入口 / ≤6 字段） | 说明与红线 |
| --- | --- | --- | --- |
| 生化化验记录（GH/IGF-1/随机GH/OGTT谷值/糖代谢） | 拍照/PDF → 候选（指标+值+单位+日期+原句） | 「⋯ 更多」表单 | 值照抄原文；无 control_status 类判读列；单位必随附 |
| 用药/注射记录 | 说/拍 → 候选 | 表单 | 零"建议调整剂量"文案 |
| 激素替代服药记录 | 说 → 候选（先选药） | 表单 | 漏服记"漏服"事实，不生成补救建议 |
| 合并症记录 | 拍报告 → 候选 | 表单 | 分节归置待核对；不进生化趋势 |
| 影像/视野报告 | PDF/拍照 → 候选 | 表单 | 术语引用原句不解释判定 |
| 复诊摘要 | 汇总候选 → 勾选确认 | 清单手工加条目 | 摘要只含已确认记录 |
| 就诊问题清单 | AI 可建议问题候选 | 手工加/删 | 患者确认才保留 |
| 随访日历节奏条目 | —（红线：复查间隔以医嘱原文为准，AI 不推算"该查了"判定） | 手工登记医嘱原文+日期 | 仅展示与提醒，不生成"无需复查"暗示 |
